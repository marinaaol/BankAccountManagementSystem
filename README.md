# Bank Account Management System (GestaoContas)

Project developed in C# as a practical programming exercise applying Object-Oriented Programming (OOP) principles, featuring encapsulation, advanced properties, data validations, exception handling, and manual unit testing.

## Features
- **Account Management:** Open accounts using different constructors (with default values or custom initial balance and overdraft limit).
- **Banking Operations:** Deposits, withdrawals, and transfers between accounts with strict validations for balances, account status, and overdraft limits.
- **History and Statement:** Automatic logging of all successful operations and a detailed statement view.
- **Security & Account Closure:** Mechanism to deactivate accounts and block transactions on closed accounts.

## Technologies Used
- Language: **C#**
- Environment: **Visual Studio / VS Code**
- Paradigm: Object-Oriented Programming (OOP)

- **Segurança e Encerrar Conta:** Mecanismo para desativar contas e bloquear transações em contas encerradas.
